# SIS257 - San Benjamin-SupraMedic

## Integrantes

Hector Fernando Duran Silva

## Tema

Sistema de gestión de inventarios, compras y ventas para San Benjamin.

## Descripción del negocio

San Benjamin es un negocio dedicado a la comercialización de productos. La aplicación permite administrar productos, categorías, clientes, proveedores, inventario, compras y ventas, facilitando el control de existencias y las operaciones principales del negocio.
